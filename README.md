# Loice Andia 

> Build, Empower, Build again

The official web page for Loice Andia Kivisi.

## Features

- **Hero section** — Introduction with a call-to-action to open the collaboration/contact form.
- **About section** — Background, skills, and technologies.
- **Experience section** — Professional work history.
- **Projects section** — Highlighted personal and professional projects:
  - **Judicial Advisor** — AI-powered legal assistant (GitHub)
  - **Alpha Babes** — Chama group portfolio platform showing contributions, investments, and insights ([alphababes.loiceandia.com](https://alphababes.loiceandia.com/))
- **Contact section** — Social links (GitHub, LinkedIn, Substack, Buy Me a Coffee), a "Say Hello" button that opens a collaboration form, and a **"Schedule a Call"** link that lets visitors book time directly via Google Calendar Appointment Scheduling.

## Contact & Scheduling

Visitors can reach out in two ways from the contact section:

- **Say Hello** — Opens an in-page collaboration form powered by Web3Forms.
- **Schedule a Call** — Opens the Google Calendar appointment scheduling page at `https://calendar.app.google/1yGmdUdcscUmoD416`.
